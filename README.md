# Fumi - 宛名印刷アプリ

macOS/ブラウザで筆まめのような宛名を印刷することができるアプリです。CSVファイルからのインポート、手動登録、PDF出力に対応しています。

## 主な機能

- **CSV インポート** - 住所録ファイルから一括登録
- **住所録管理** - 追加、編集、削除、検索、フィルタリング
- **郵便番号自動入力** - zipcloud API で住所を自動補完
- **宛名面印刷** - 日本郵便規格準拠のはがき印刷
- **裏面印刷** - 年賀状テンプレート付き
- **PDF出力** - 印刷用PDFの生成
- **差出人管理** - 差出人情報の登録・変更
- **位置補正** - 印刷位置のキャリブレーション（±15mm）
- **Undo/Redo** - 操作の取り消し・やり直し
- **レスポンシブ対応** - PC/タブレット/スマートフォン対応

## 使用方法

### CSVからのインポート

1. **CSVファイルを準備**
   - 以下のカラムを含むCSVを用意してください（BOM付きUTF-8推奨）
   ```csv
   カテゴリ,企業名,名前,フリガナ,郵便番号,住所,電話番号,備考
   業務用,株式会社テスト,山田太郎,ヤマダタロウ,100-0001,東京都千代田区丸の内1-1-1,03-0000-0000,テスト用
   ```

2. **CSVをアップロード**
   - メイン画面のドロップゾーンにCSVファイルをドラッグ＆ドロップ
   - または「ファイルを選択」ボタンをクリック

### 手動登録

1. 「+手動登録」ボタンをクリック
2. フォームに企業名（必須）、名前、郵便番号（必須）、住所（必須）を入力
3. 郵便番号を入力すると自動で住所が補完されます
4. 「追加」ボタンをクリック

### 印刷

1. 宛名面を印刷する場合 → 「宛名面印刷」ボタン
2. 裏面を印刷する場合 → 「裏面印刷」ボタン
3. 位置を微調整する場合 → 「位置補正」でキャリブレーション

### PDF出力

- 「PDF出力」ボタンで印刷用PDFを生成

## 郵便番号検索 API について

- **API** zipcloud (https://zipcloud.ibsnet.co.jp/)
- **リクエスト間隔** 1秒以上の間隔が必要
- **レート制限** 1日のリクエスト数に上限あり
- **タイムアウト** 3秒でタイムアウト（自動リトライ可能）

## データ保存について

- **保存先** ブラウザの IndexedDB（ローカルストレージ）
- **同期** 自動的にローカルで保存されます
- **他のパソコンに移す** CSV エクスポートで可能

## よくある質問（FAQ）

**Q: データはどこに保存されますか？**
- A: ブラウザの IndexedDB に保存されます。他のパソコンやブラウザからはアクセスできません。

**Q: 他のパソコンにデータを移せますか？**
- A: 「エクスポート」ボタンでCSVファイルとしてダウンロードし、別のパソコンで「インポート」すれば、データを移行できます。

**Q: 郵便番号から住所を自動補完できない場合は？**
- A: インターネット接続を確認し、zipcloud APIが利用可能か確認してください。手動で住所を入力することもできます。

**Q: 印刷位置が正確でない場合は？**
- A: 「位置補正」機能で微調整できます。左右（X）と上下（Y）を ±15mm の範囲で調整可能です。

**Q: macOSのプリンタ設定は？**
- A: 用紙サイズを「はがき」（100mm × 148mm）に設定してください。A5サイズでもご利用いただけます。

## トラブルシューティング

**CSVインポートが失敗する場合**
- ファイルが UTF-8 形式で保存されているか確認
- ファイルサイズが 5MB 以下か確認
- 必須カラム（企業名、郵便番号、住所）が含まれているか確認

**印刷がうまくいかない場合**
- ブラウザの印刷プレビューで確認してから印刷してください
- 用紙サイズ設定を「はがき」に変更してください
- 位置補正でオフセットを調整してください
